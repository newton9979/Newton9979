## ⚙️ DevOps / SRE — What I Do

- Manage **CI/CD pipelines with Jenkins** for automated build, deployment, release, and rollback across Dev, QA, Staging, and Production
- Use **Git/GitHub** for source control — branching, merging, tagging, pull requests, and release management
- Automate builds with **Maven** and manage artifacts via **Nexus** and **Artifactory**
- Build, troubleshoot, and deploy **Docker containers**; manage **Kubernetes** Deployments, Services, ConfigMaps, Secrets, Ingress, and HPA
- Resolve Kubernetes issues — pod failures, CrashLoopBackOff, image-pull errors, scheduling and rollout failures
- Provision AWS infrastructure with **Terraform** and automate configuration with **Ansible**
- Manage **AWS EC2, VPC, S3, IAM, RDS, Lambda, and CloudWatch** for infrastructure operations and monitoring
- Implement monitoring/observability with **Prometheus, Grafana, and CloudWatch**
- Run **code quality & security scans** using SonarQube, Snyk, and Trivy
- Own on-call responsibilities — **incident response, RCA, and post-incident reviews**

- Handle **SSL certificate lifecycle** — installation, binding, renewals
- Execute **DR drills**, DC-to-DR switchovers, and switchbacks, validating application/database/transaction availability
- Coordinate **Incident, Problem, Change, and Release Management** following ITIL practices; maintain SOPs and runbooks
